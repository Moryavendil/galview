# GalView
Bare-bones viewer for heavily annotated PDFs.

Shows the PDF with all annotations, highlights, etc. on a side panel. Should never miss a comment.
Annotations can be checked or dismissed if they have been reviewed.

Basic PDF functions (zoom, serach) are supported.

Usage:
    python galview.py [file.pdf] [--page N]

Requires: PyMuPDF, PySide6
